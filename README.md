# Hide and Show Password

A lightweight vanilla JavaScript project that lets users toggle password visibility in a simple input field.

## Features

- Show or hide password text with an eye icon
- Clean and responsive UI
- No framework or build tools required
- Easy to run locally in any browser

## Project Structure

- `index.html` — page structure and password input
- `style.css` — styling for the form and layout
- `script.js` — toggle logic for showing/hiding the password
- `eye-open.png` and `eye-close.png` — icons used for the visibility toggle

## How to Run

1. Open the project folder in your browser.
2. Launch `index.html` directly, or serve the folder with a local web server.
3. Type a password in the input field and click the eye icon to toggle visibility.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
